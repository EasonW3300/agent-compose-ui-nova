# AI 助手环境变量引导设计

## 目标

让非技术用户在新建 AI 助手的“高级设置”中理解环境变量的用途、左右输入框含义与何时无需填写，同时不改变草稿或后端的环境变量数据结构。

## 范围与约束

- 仅修改 `src/ui/steps/TaskStep.tsx` 和与其配套的 `src/ui/setup.css`、测试文件。
- 左侧输入框明确为“变量名”，右侧明确为“变量值”。
- 在“变量值”旁提供键盘可达的小问号；鼠标悬停或键盘聚焦时显示说明。
- 显示三条只读示例：`TZ=Asia/Shanghai`、`LANG=zh_CN.UTF-8`、`HTTPS_PROXY=http://proxy.example:8080`。
- 说明必须包含“通常无需填写”，并提醒 AI 引擎 API Key 应在“设置 → AI 引擎密钥”配置。
- 不新增保存逻辑、默认变量、网络请求或依赖；用户未填写时仍保存空数组。
- 保留已有中文文案、键盘操作和 `env: { key, value }[]` 映射。

## 交互与可访问性

- 每个输入框使用可见文本标签，并维持现有的无障碍名称“变量名”与“变量值”。
- 小问号为 `button`，带有“查看环境变量说明”的无障碍名称。
- 说明气泡通过 CSS 在 hover 与 focus-visible 时展示，因此鼠标和键盘用户获得相同信息。
- 示例作为静态文本，不会自动写入用户草稿或覆盖已输入内容。

## 验证

- 在 `TaskStep.test.tsx` 新增回归测试，检查字段标签、说明按钮、核心提示和三条示例。
- 完整运行 `npm test`、`npm run lint`、`npm run build`。
